Основной паттерн, по которому строятся все фреймворки по авт.тестированию -- Page Object Model (POM)
Этот паттерн основывается на принципах ООП (на классах)

В рамках этого паттерна каждая страница представляется и описывается в виде объекта: для каждой страницы с тестом создаётся отдельный класс

Каждый файл из этой папки содержит в себе описание страниц, на которых проводим тестирование: есть "Логинка" - описываем страницу (элементы, методы и т.п.)

Наверху всех этих классов будет стоять один "абстрактный" класс -- base_page (родительский для всех последующих классов):
он нужен для хранения методов, свойств, которые будут актуальны для всех страниц
